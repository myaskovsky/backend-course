# Нефункциональные требования

- Оптимизация запросов к БД (индексы, `select` только нужных полей), наличие транзакций где необходимо
- Health checks (`/health`) для мониторинга
- Rate limiting (защита от DDoS/брутфорса)
- Валидация всех входных данных (class-validator)
- CORS — только доверенные домены
- Логирование всех критических событий (вход, ошибки, изменения данных)
- Покрытие тестами ≥ 80% (unit + integrational)
- OpenAPI (Swagger) — актуальная документация
